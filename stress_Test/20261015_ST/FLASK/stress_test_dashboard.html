Run evidence

Read the verdict correctly

Reliability = workflows successful within target ÷ all measured workflows. Late answers miss the target. A completed experiment can fail its reliability requirement.

¹ Failures include FAILED, DEADLINE_EXCEEDED and INTERRUPTED. Percentiles use nearest rank and include successful-but-late answers. The 1-client baseline has a small sample; one passing run does not establish long-term reliability.

Scope and attribution

This tests the direct Supervisor client workflow, including citation resolution, not the Flask app or model execution time alone. Invocation success is tracked separately from workflow success.

Workers issue requests continuously without employee think time. The runs do not test 500 clients or establish a validated production capacity. Missing HTTP responses or generic exception chains require additional server-side investigation.
